# Suprnova LSP

Suprnova LSP is a Rust language server focused on the Suprnova framework. It
combines source analysis with compiler-produced rustdoc declarations so model
methods generated by Suprnova macros can participate in hover, completion and
type inference. It runs independently of rust-analyzer.

The engine indexes saved workspace declarations and can offload package data to
disk between requests. Open-file analysis handles supported unsaved edits. Low
settled memory remains a design goal; compiler exports and indexing can use more
memory while they run.

For Suprnova workspaces, a supervised background worker discovers models and
Cargo targets, exports declarations on startup, and refreshes after debounced
saved-input changes. Explicit prepared exports and source-only operation are
also available. Rustdoc declarations do not provide general unsaved proc-macro
expansion or rust-analyzer's full semantic coverage.

Start with [Installation](../usage/INSTALL.md) and
[Configuration](../usage/CONFIGURE.md). The
[repository README](https://github.com/eas4ai/suprnova-lsp#readme) describes supported model behavior,
toolchain requirements, GitHub release packages and upstream attribution.
